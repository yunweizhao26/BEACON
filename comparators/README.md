# Comparator evidence

Saved predictions are in the data bundle. No comparator source is vendored. Upstream commits, package versions, complete recorded environments, and the scRegNet configuration are in [manifest.json](manifest.json). Commits are recorded checkout identities; this build did not verify local upstream diffs or refit comparators.

| Comparator and upstream | Configuration and adapter behavior | Recorded environment |
|---|---|---|
| [GNNLink](https://github.com/sdesignates/GNNLink) | TensorFlow compatibility graph/session, seed reset, 100 epochs; supplied positives build adjacency plus identity, supplied unlabeled pairs provide the negative mask; read the complete logits matrix and select frozen eligible edges. Raw expression and the separately reported FA input are retained. | Python 3.10.20, TensorFlow CPU 2.20.0, NumPy 2.2.6, Torch 2.11.0; Torch is also imported by upstream utilities. |
| [GCLink](https://github.com/Yoyiming/GCLink) | Released attention model; 20 pretraining and 20 training epochs, batch 256, learning rate .003, edge removal .2, contrastive weight .5, temperature .2. Frozen positive/unlabeled pools replace the upstream split. | Core environment: Torch 2.11.0, NumPy 2.2.6, SciPy 1.15.3, scikit-learn 1.7.2. |
| [scRegulate](https://github.com/YDaiLab/scRegulate) | Maximum 10,000 epochs; batch floor(.85 × cells), at least one; freeze 4,500 epochs; learning rate .0001; alpha max 1 and scale .0025; patience 4,500; min targets/TFs zero. Import the training modules through a package stub. Zero-target ULM estimates become zero, undefined P values become one. | Core environment plus AnnData .11.4, Scanpy 1.11.5; complete receipt in manifest. |
| [RegGAIN](https://github.com/SDU-Math-SunLab/RegGAIN) | 500 epochs, learning rate .001, k=50, adjacency powers [0,1,2]; first widths [80,80,10], subsequent widths 40/40/5 and 16/16/2; pos=10; edge weights .6/.3/.3/.3 and node weights .5/.2/.2/.2. Primary scores retain the released orientation; the alternative orientation is separate evidence. | Core plus torch-geometric 2.8.0.post1, AnnData and Scanpy. |
| [GENELink](https://github.com/zpliulab/GENELink) | 20 epochs, batch 256; hidden widths 128/64/32, output 16, two three-head attention layers, alpha .2, dot decoder, concatenation; Adam .003, StepLR gamma .99. Supplied training pairs and frozen eligible pool; no refitted test split. | Core Torch environment. |
| [GENIE3](https://github.com/aertslab/arboreto) | Arboreto random forests with eligible TFs, per-task seed and upstream parameters. Full-network scores reused across fixed test pools; absent edges score zero. | Arboreto .1.6; NumPy 2.2.6, scikit-learn 1.7.2. Original distributed scheduler dependencies are not needed to rescore saved predictions. |
| [GRNBoost2](https://github.com/aertslab/arboreto) | Arboreto SGBM parameters, seed 42 per target, self predictor removed, importances multiplied by tree count. Joblib target scheduling replaces Dask. The [paired monitor](monitor.py) measures before/after loss on the **same** out-of-bag mask and applies the 25-round mean-improvement rule. Standard and paired-monitor outputs are identified separately. | Arboreto .1.6, scikit-learn 1.7.2, Joblib 1.5.3, NumPy 2.2.6. |
| [Inferelator 3.0](https://github.com/flatironinstitute/inferelator) | Single-cell TFA/BBSR, no gold standard, supplied prior and TF list, Joblib scheduling. One bootstrap for generic/TRRUST adapter; five bootstraps for RPE1. Target-by-regulator confidence orientation is explicitly mapped to ordered pairs; missing pairs score zero. | Package 0.6.3 at the recorded source commit, plus core NumPy/SciPy/Pandas/scikit-learn environment. “3.0” is the manuscript method name; the checkout pin is authoritative. |
| [scRegNet](https://github.com/sindhura-cs/scRegNet) | Reported mHSC-E panel only. Geneformer penultimate token features averaged over detected cells; released GCN/BCE. Batch 133, hidden 256, RMSprop learning rate .0012056391735792479, weight decay 4.6205759922095423e-7, dropout .5095606629916417. Up to 300 epochs; validation AUROC every five epochs, patience ten evaluations; dropout zero for prediction. | Core Torch; the Transformers package version and checkpoint download location were not traced in the inspected receipts; saved embeddings/predictions remain the reproducible evidence. |

External adapters preserve the source restrictions of the curated prior and exclude all supplied training pairs and self pairs when reporting discovery metrics. Comparator configuration does not authorize selecting hyperparameters from test labels. No install or fit is required for the release evaluator.
